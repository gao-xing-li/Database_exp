## 当前实现

应用沿用15张业务表，增加WebUser认证、编号序列、受限SQL身份和顾客订单行级过滤。店长维护商品和库存，店员登记及结账，库存员管理数量，顾客查询在售商品和本人订单。

首次登记核对目录标价并保存单价，修改数量、刷新和结账沿用登记价格。页面标价过期时提示刷新核对。结账将库存扣减与订单完成放在同一事务中，失败整单回滚。

现货流程已实现。预售履约、采购验收及到货数量与整单状态联动仍是后续范围。第六周只对三项采购约束实施保留数据的迁移。

## 运行与验证

Windows安装Conda、准备SQL Server和日常启动，统一见[运行说明](第二阶段提交/README.md)。日常启动在已激活的环境中进入`第7-9周业务产出`，执行`python run.py`，浏览器打开`http://127.0.0.1:5000`。已有数据库时直接启动应用。

最近保留的完整测试记录为48项通过，其中42项连接SQL Server、6项验证密码重设辅助。完整浏览器流程7组通过，角色页面另有21项只读检查，订单刷新另有3项检查。第六周45项迁移回归单独统计。[当前验证记录](第7-9周业务产出/03_测试与验证记录.md)列出结果入口与覆盖范围，历史证据另行标识。

手动补拍范围见[实机截图清单](第7-9周业务产出/05_本轮实机截图清单.md)。尚待本人补拍的内容按清单继续完成。
