## 图的读法

矩形表示实体，主码属性加下划线，菱形表示联系。实体与菱形之间的 min..max 表示**本端每个实体参与该联系的次数**：类别端 0..*、商品端 1..1 表示一个类别可有多个商品，每个商品恰好有一个类别。最小值表达可选/必须参与，不与原 UML 对端读法混用。

AK、AK1、问号和斜线是本项目辅助属性标记，见图例；N 编号补充状态和类型条件；Δ1、Δ2 标明本周收紧而 v0.1 尚未完整落实的采购要求。

## 现场展示

在 SSMS 连接已有第一阶段数据库，打开 `04_只读验证.sql`，逐段执行三个 SELECT：

1. SO004：订单包含两种商品，对应订单—明细—商品。
2. SO001、SO002：散客与会员购买，对应会员可选参与。
3. P003：库存与可售量，对应商品—库存。

前提是已有第一阶段样例和 `vw_OrderDetail`、`vw_InventoryStatus` 视图。视图缺失或查询为空时，先确认连接的实例和初始化情况。文件不会自动建表、建视图或导入样例。具体预期和观察见验证记录。
