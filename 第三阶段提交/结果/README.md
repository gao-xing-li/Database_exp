## Chrome 库存页实测

2026-11-27，使用 `inventory` 登录本机经营工作台，在阶段样例库 `AnimeGoodsStoreDB_Week6App_Stage3` 调整 P003「三月七毛绒玩偶」。各步预留量均为 0，可售量与实际库存相同。

| 页面操作 | 实际库存 | 补货警戒值 | 建议补货量 | 库存状态 |
|---|---:|---:|---:|---|
| 打开库存页 | 2 | 3 | 1 | 需要补货 |
| 输入盘盈 1 件和原因，点击「确认调整」 | 3 | 3 | 0 | 充足 |
| 只填新警戒值 5，点击「仅更新警戒值」 | 3 | 5 | 2 | 需要补货 |
| 刷新页面 | 3 | 5 | 2 | 需要补货 |
| 输入 −1 和恢复原因，将警戒值调回 3，确认调整 | 2 | 3 | 1 | 需要补货 |

在 SSMS 查询 `dbo.InventoryAudit` 中 `product_id = 3` 的全部记录，共两条，业务类型均为 `ADJUSTMENT`，员工编号均为 2。流水 1（来源 1）记录 2→3，原因为「B浏览器验收：P003盘盈1件」。流水 2（来源 2）记录 3→2，原因为「B浏览器验收：恢复P003样例库存」。中间单独修改警戒值时未新增库存流水。
