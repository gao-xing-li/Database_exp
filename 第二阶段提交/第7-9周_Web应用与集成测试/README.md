# 第7—9周 Web应用与集成测试

本阶段按指导书合并验收，代码与设计记录覆盖第7—9周。第7周建立分层和核心操作，第8周组织库存与订单事务，第9周进行集成与流程验证，实际实施边界见设计与决策。

## 按周定位

第7—9周共享一套应用，下面按任务重点定位文件，同一业务文件会同时支撑多个周次。

| 周次重点 | 对应文件 |
| --- | --- |
| 第7周，应用基础、分层、登录与商品操作 | [架构设计](01_架构与接口.md)，代码/web/app下的路由、db.py、repository.py及页面 |
| 第8周，库存、草稿订单、结账与事务 | 代码/web/app/services.py、repository.py，操作步骤见[操作手册](02_操作手册.md) |
| 第9周，集成测试、角色流程与结果整理 | 代码/web/tests、scripts/browser_smoke.py，[测试结果](测试结果/pytest.xml)及截图_角色流程 |
