## 关键观察

| 检查 | 已有执行结果 |
| --- | --- |
| 登记前标价 | 过期、缺少、非法或自行改低标价被拒绝，新登记须核对目录价 |
| 登记后调价 | 20元登记后目录调为25元，改数量和结账仍使用20元，新订单采用25元 |
| 多商品结账 | 3×12.50加2×20为77.50，目录后来改为15元时原明细仍按12.50元结算 |
| 完整浏览器价格流程 | 25元登记后目录改为30元，3件显示75元，恢复2件结账50元，库存10减到8 |
| 整单回滚 | 后处理商品不足时，前面已执行的扣减也撤销，订单保留草稿和登记单价 |
| 并发库存 | 实际3件、预留1件，两个订单各买2件，结果一笔成功、一笔库存不足，最终实际1件、预留1件 |
| 权限 | 直接API越权和顾客跨会员请求被拒绝，受限SQL账户越权返回229，顾客SQL查询受RLS限制 |
| 连接失败与日志 | 不可用端口得到503，可按请求编号找到后端日志，页面保持简明提示 |

首轮新增价格测试曾得到47通过、1项日志读取失败，定位为Windows默认编码读取UTF-8日志。明确读取编码后全量复跑48项通过，失败过程保留在AI记录，当前结果文件使用复跑成功版本。
